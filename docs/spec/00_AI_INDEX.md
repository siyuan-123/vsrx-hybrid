# VSR-X AI 上下文索引

## 一句话架构

PP-OCRv6 Small 负责字幕发现，运动补偿 TBE 负责优先恢复真实背景，Telea/LaMa 只补 residual mask，官方 ProPainter 只处理困难 ROI，统一质量门决定通过、局部升级或人工复核。

## 不可违反的系统不变量

1. 不跨镜头引用任何帧、光流、轨迹或 clean plate。
2. 非字幕区域默认保持源像素；模型输出只在受控软掩膜内合成。
3. OCR 不逐帧全画面运行；重模型不处理无关帧和无关像素。
4. 所有 GPU 路径有显存预测、块长上限和 OOM 降级。
5. 视频只做一次最终有损编码；音频优先 stream copy。
6. 所有阶段幂等、可断点、可审计；失败不得静默通过。
7. 阈值不是常数真理，必须由 Golden Set 校准并版本化。

## 术语

- **ROI**：仅包含字幕及必要上下文的处理区域。
- **TBE**：Temporal Background Exposure；利用其他帧暴露的真实背景恢复当前帧。
- **Clean Plate**：不含字幕覆盖的背景估计及其置信度图。
- **coverage**：目标掩膜中由可信真实像素恢复的比例。
- **confidence**：配准、光流、可见性、颜色一致性等综合可信度。
- **residual mask**：TBE 之后仍未恢复的像素，只允许后续模型处理这些像素。
- **质量门**：残字、闪烁、接缝、保真、清晰度和颜色指标组成的自动验收层。
- **困难片段**：真实背景覆盖不足、前景穿越、高运动、大残洞或前级质量门失败的片段。

## AI 输出代码时的最低要求

- 类型明确，错误码稳定，外部进程有超时、取消和重试。
- 每个片段记录路由原因、模型版本、峰值显存、耗时和 QC 指标。
- 单元测试覆盖数学和状态机；集成测试覆盖 VFR、切镜、OOM、崩溃恢复和非字幕区保真。
- 不允许用“整条视频重新跑”代替片段级恢复。
