# 核心算法细节

## 1. 为什么不是“一个模型处理全部帧”

硬字幕后面的真实像素通常会在邻近帧中重新出现。直接用生成模型会浪费资源，并可能产生纹理漂移或错误内容。VSR-X 的顺序是：

```text
真实像素恢复 > 极小洞传统修补 > 单帧神经修补 > 视频生成修补
```

## 2. 字幕发现

### 2.1 抽样

自动模式不会每帧全画面 OCR。抽样由以下信息共同决定：

- 开头、中段窗口、结尾；
- 镜头首帧；
- `full_frame_sample_interval_seconds`；
- 周期性全画面复扫；
- 固定 ROI 提示。

短视频的抽样索引会去重，避免同一帧被多个窗口重复检测。

### 2.2 PP-OCRv6 detection-only

RapidOCR 适配器调用底层检测阶段，不加载识别网络。输入只限制最大边，不会把低分辨率视频无意义放大到 736 像素短边。输出包括多边形、置信度和可用时的概率图。

若 RapidOCR 不可用，启发式检测器根据局部高对比、边缘密度和连通域给出候选。该降级能让流水线运行，但不是复杂字幕的质量替代品。

## 3. 轨迹关联与保护

相邻检测使用加权代价：

```text
cost = w_iou * (1 - IoU)
     + w_center * normalized_center_distance
     + w_height * height_ratio_error
     + w_angle * angle_error
     + w_appearance * appearance_error
```

Hungarian 求最小总代价；Kalman 预测缺失帧位置。每个镜头独立重置。

轨迹分类综合：

- 屏幕坐标稳定度；
- 出现/消失节奏；
- 位置先验；
- 局部对比；
- 是否与场景运动解耦；
- 长期不变、角落小标记、与场景运动耦合等惩罚。

默认保护不确定轨迹。`--aggressive` 才允许删除分类不确定的文字，这会提高误删风险。

## 4. 精细掩膜

基础多边形不足以覆盖描边、阴影、发光和底板。处理顺序：

1. 概率图或多边形光栅化；
2. 按文字高度和分辨率计算膨胀半径；
3. 在 Lab/灰度局部区域扩展与文字相连的高对比组件；
4. 检测偏移阴影和光晕；
5. 轨迹足够可信时检测半透明矩形底板；
6. 形态学闭运算、填洞、移除微小噪声；
7. 把前后帧 mask warp 到当前帧后做时间并集；
8. 生成硬掩膜与羽化 alpha。

外部掩膜模式直接使用用户提供的逐帧 mask，但仍会做尺寸校验、二值阈值和必要的时序处理。

## 5. 运动补偿 Clean Plate

### 5.1 相邻帧运动缓存

不是对“每个目标帧 × 每个参考帧”重复计算配准。每个镜头先计算相邻帧变换：

```text
T(i -> i+1)
```

跨帧变换通过矩阵组合获得：

```text
T(i -> j) = T(j-1 -> j) ... T(i -> i+1)
```

当组合置信度过低时才做目标到参考的直接重配准。

### 5.2 全局配准

方法按成本排序：

1. 静态/近静态快速门；
2. phase correlation 平移；
3. ECC 仿射；
4. ORB + RANSAC 仿射；
5. identity 降级。

配准评价只在字幕掩膜外的有效环带上计算，避免字幕内容影响运动估计。

### 5.3 局部光流

若全局对齐后的误差小且有效比例高，直接接受，不运行光流。只有局部非刚性运动或误差超过阈值时，才在字幕 ROI 加上下文后运行 OpenCV DIS。

正反向一致性：

```text
|| F(a->b)(p) + F(b->a)(p + F(a->b)(p)) || < threshold
```

不一致像素视为遮挡或不可靠，不进入融合。

### 5.4 参考帧评分

每个候选参考帧的分数由以下因素组成：

- 时间距离衰减；
- 正反向运动一致性；
- 掩膜外环带光度误差；
- 梯度一致性；
- 字幕遮挡后有效像素比例；
- 曝光补偿可拟合程度。

只选择最高分的有限参考帧，控制内存和计算量。

### 5.5 曝光补偿

在未遮挡环带拟合每通道仿射：

```text
I_target ≈ a * I_reference + b
```

使用鲁棒统计限制 `a`、`b`，防止闪光、自动曝光或压缩噪声导致过校正。

### 5.6 逐像素融合

每个目标像素收集通过可见性和置信度检查的参考值。默认使用加权中位数而不是平均值，以拒绝经过字幕区域的人物、物体和光照异常。

输出：

- `clean_frame`：已恢复区域；
- `coverage_map`：每像素是否有足够参考；
- `confidence_map`：参考数量、运动和光度一致性的综合分数；
- `residual_mask`：仍需修复的像素。

## 6. 路由

路由按片段而不是整条视频决定。起始逻辑：

```text
mask empty
  -> COPY
coverage >= 0.90 且 confidence >= 0.76
  -> TBE_ONLY
残洞非常小
  -> TBE_TELEA
coverage >= 0.55 且残洞比例较低
  -> TBE_LAMA（LaMa 不可用则 Telea）
低覆盖 / 低运动置信度 / 前景穿越字幕
  -> OFFICIAL_PROPAINTER
显存不足或 ProPainter 不可用
  -> STTN / LaMa / Telea 逐级降级
```

阈值是工程起点，不应视为适用于所有素材的真理。必须通过自己的 Golden Set 标定。

## 7. 修复后端

### 7.1 Telea / Navier-Stokes

适合纯色、渐变和极小残洞；无需模型。处理大纹理洞会产生拖影，因此只作为微小洞或最终降级。

### 7.2 LaMa ONNX

只裁剪 residual mask 包围盒并增加上下文。动态 ONNX 输入补齐到 8 的倍数，固定输入图则按模型尺寸缩放。推理后严格合成回原图。

### 7.3 MI-GAN ONNX

可选 CPU 经济后端；默认关闭。只有提供权重且配置启用时使用。

### 7.4 官方 ProPainter

- 仅处理困难 ROI；
- 当前片段临时导出帧与掩膜；
- 独立进程、FP16、固定 CUDA 设备；
- 监控退出码、超时和 OOM；
- 输出帧数必须与输入相同；
- 最终只在掩膜内合成。

### 7.5 官方 STTN

仅作低显存紧急降级，不是默认质量基线。

## 8. 质量门

每次尝试检查：

- 残余文字概率以及相对输入的下降比例；
- 光流对齐后的时间闪烁；
- 掩膜边界颜色和梯度突变；
- 修复区锐度相对邻域是否异常；
- 硬掩膜外像素是否被修改。

失败重试阶梯：

```text
扩大掩膜
  -> 升级运动估计与参考帧
  -> residual LaMa
  -> 官方 ProPainter
  -> 标记 review_required
```

“需要复核”是显式结果，不是静默成功。
